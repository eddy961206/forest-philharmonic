# 야외 전용 24곡의 판본과 출처

홀 41곡, 스피어 41곡, 야외 24곡은 곡 ID가 서로 겹치지 않는 고유 106곡이다. 야외에 먼저 추가한 8곡은 유지하고, 다른 공연장과 공유하던 16곡은 새로운 작품으로 교체했다. MIDI는 음표·쉼표·템포·다이내믹을 가진 악보 데이터다. 녹음이나 YouTube 오디오를 재생하지 않는다. 아래의 전곡은 선택한 작품·악장·편곡 판본 전체를 뜻한다. 악보가 지시한 반복과 D.C.는 연주하지만 길이를 채우려고 도입부를 복제하지 않는다.

## 기존 8곡의 판본 확인

- 사랑의 인사·유모레스크·세레나데·아베 마리아·자장가는 지휘자 없는 2중주로 연주한다. 각 독주 선율은 지정한 단원 1명이 맡는다. 짐노페디도 지휘자 없는 피아노 독주이며, Air와 교향곡 40번은 지휘자가 있는 합주다.

- 모차르트 40번 1악장: MusicXML 총보 299마디, 제시부 반복을 펼친 MIDI는 399마디다. 플루트·오보에·클라리넷·바순·호른 2부·제1/2바이올린·비올라 2부·첼로의 11개 실제 트랙을 보존했다. 비올라의 분할 성부와 두 호른을 서로 다른 악기로 잘못 읽지 않도록 명시 배정했다. 선택한 판본의 마지막 성부는 `VC`로 기재되어 있고 별도의 콘트라베이스/옥타브 중복 지시는 없다. 이 판본 그대로 첼로로 연주하며 원전 총보와 동일한 모든 악기 배치를 보장하지 않는다.
- 해당 모차르트 원본에는 숫자 템포가 없고 MIDI에는 기본값 ♩120이 들어 있다. Molto allegro에 맞춰 이번 연주는 ♩220으로 설정했다. 음표·마디·반복은 제거하지 않았다.
- 유모레스크: 64마디 바이올린·첼로 2중주 판본 전체다. 두 악기의 arco/pizzicato 프로그램 전환과 실제 원본 음표를 보존했다. 원래 피아노 독주나 원전 관현악 총보라고 표시하지 않는다.
- 사랑의 인사: 바이올린·피아노 100마디 전체. 세레나데: 호른·피아노 82마디 전체. PDMX 네 곡 모두 `license_conflict=False`이며 압축 MusicXML 안에도 상충 권리 선언이 없음을 확인했다.
- 바흐 Air: Mutopia 242 총보 MIDI 전체. D장조 현악 4성부이며 후대의 C장조 독주 바이올린 편곡과 구분했다. 소스와 파생 JSON은 CC BY-SA 3.0을 유지한다.
- 짐노페디: Mutopia 37 피아노 악보 전체를 0.8배 속도로 연주한다. 브람스 자장가는 한 절의 악보 전체이며 성악 선율만 첫 번째 클라리넷 단원 1명으로 바꾸었다. 자장가 55초는 곡의 한 절이 짧기 때문이며 도입 모티프를 잘라낸 것이 아니다.
- 구노 아베 마리아: 바흐 전주곡에 구노의 선율이 더해진 1856년 Heugel 바이올린·피아노 판본 전체다. 기존 `bach-prelude-c`와는 다른 작품으로 등록했다.

## 새 16곡의 변환과 표시

- **사랑의 꿈·이별의 곡·환상즉흥곡**: 피아노 독주 전곡이다. 원본 템포 변화와 루바토를 보존했다. 사랑의 꿈은 89마디, 이별의 곡은 78마디이며, 환상즉흥곡은 느린 중간부와 재현·코다까지 포함한다.
- **백조**: 원본은 첼로와 피아노 2대의 28마디 판본이다. 모든 피아노 음표를 앱의 피아노 한 대로 통합한다. 피아노 2대가 무대에 실제로 있거나 두 연주자의 동작을 재현한다고 표시하지 않는다. **군대행진곡**도 피아노 네 손 원본의 성부를 한 대로 통합하며 네 손의 개별 동작은 구현하지 않는다.
- **타이스 명상곡**: Avery Bell의 공개 B♭장조 튜바·피아노 편곡을 D장조 바이올린·피아노로 재편성했다. 전 성부 +4반음, 독주는 추가 +24반음으로 옮겼다. 71마디 전체의 시간·리듬·다이내믹은 유지했다. 원전 관현악판이라고 표시하지 않는다.
- **보케리니 미뉴에트**: jwberns의 G장조 현악 5중주 판본이다. MusicXML 마지막 마디의 `Menuett D.C.` 지시가 원본 MIDI에서 빠져 있어, 원본의 미뉴에트 24마디를 트리오 뒤에 복원했다. MIDI의 [0,24)박과 [48,96)박을 312박부터 연결해 총 384박이 된다. 음높이를 바꾸거나 새 선율을 만들지 않았다.
- **예수, 인간 소망의 기쁨**은 74마디 관현악·합창 편곡이다. 잘못된 피아노 프로그램을 오르간·합창·제2바이올린 파트 이름에 맞춰 배정했다. **바디네리**는 44마디와 악보 반복을 담은 6관악 편곡이며 원전 플루트·현악 편성으로 표시하지 않는다. **사라방드**는 주제·두 변주·주제 재현을 담은 64마디 현악 편곡이다.
- **토카타와 푸가**는 Mutopia 1780의 오르간 전곡이다. 불확실한 작곡 연도는 기재하지 않는다. **피가로의 결혼 서곡**은 294마디 관현악 판본이다. 독립 트랙 포트 처리를 사용해 다른 트랙의 프로그램 설정이 플루트·오보에 음색을 덮는 원본 MIDI 충돌을 해소했다.
- **꽃의 이중창**은 111마디의 두 성악 성부와 관현악 판본이다. 성악 음표는 합창 음색으로 연주하고 가사를 발음하지 않는다. MIDI 템포 맵의 실제 4분 45초를 사용하며, PDMX CSV의 단순 길이 추정치 151초를 연주시간으로 사용하지 않는다.
- **겨울 1악장**은 Mutopia 351의 `winter-score.mid`다. LilyPond의 4/4, 63마디, ♩140 설정은 108초다. 이번 연주는 ♩70으로 설정해 216초를 연주한다. 음표·쉼표·성부는 삭제하지 않았다. 이는 앱의 편집 템포이며 작곡가의 숫자 템포로 주장하지 않는다.
- **밤의 여왕 아리아**는 99마디 SATB 리코더 편곡의 음표를 플루트·오보에·클라리넷·바순에 배치한 4관악 편곡이다. 원곡 소프라노 가창과 관현악 편성을 재현한다고 표시하지 않는다.

### 세비야의 이발사 서곡: 실제 현악 주법 복원

원본 MIDI에서 제2바이올린·비올라·첼로·더블베이스의 아르코와 피치카토 프로그램이 같은 채널에 겹쳐 대부분의 음이 피치카토로 읽혔다. 독립 트랙 라우팅과 함께 원본 MusicXML의 실제 주법 지시 위치에 프로그램 전환을 복원했다. 모든 현악을 일괄 아르코로 바꾸지 않는다.

MusicXML divisions 24와 MIDI ticksPerBeat 480을 대응시켰다. 선행 마디는 120 tick이고 전체는 양쪽 모두 507000 tick이다. 마디 중간 지시도 반영했다. 예를 들어 17마디의 아르코 복귀는 제2바이올린 31560, 비올라 32040, 첼로·더블베이스 32520 tick이다. 제2바이올린·비올라의 11–17마디, 첼로의 91–115마디 등 실제 피치카토 구간은 유지했다. 별도 트레몰로 채널도 유지했다.

원본은 `tools/scores/rossini-barber-overture.mid`와 `.mxl`, 사용본은 `rossini-barber-overture-articulated.mid`다. `tools/restore_barber_articulation.py`로 복원하고 `tools/scores/rossini-barber-articulation-transitions.json`에서 경계를 확인할 수 있다. 모든 원본 non-program 이벤트의 트랙·절대 시각·내용·동일 시각 순서는 보존된다. 1·91·209마디에서 제2바이올린과 첼로의 음높이·시작 시각을 MusicXML과 대조했다.

## 재현

원본 MIDI는 `tools/scores/`, 출처·판본·기여자·SHA-256은 `tools/repertoire.json`, 파생 연주 데이터는 `public/music/`에 있다. 기존 변환기와 `mido==1.3.3`만 사용한다.

```sh
python3 -m pip install -r tools/requirements-music.txt
python3 tools/build_repertoire.py elgar-salut-damour dvorak-humoresque-7 bach-air mozart-symphony-40 satie-gymnopedie-1 schubert-serenade gounod-ave-maria brahms-lullaby
python3 tools/build_repertoire.py --check elgar-salut-damour dvorak-humoresque-7 bach-air mozart-symphony-40 satie-gymnopedie-1 schubert-serenade gounod-ave-maria brahms-lullaby
```

타이스·보케리니의 파생 MIDI는 `python3 tools/prepare_outdoor_chamber.py --check`로 원본에서 메모리 재생성해 바이트와 SHA를 대조한다. 변환 근거는 `tools/outdoor-chamber-proof.json`에 있다.

위 재현 명령은 기존 8곡 예시다. 신규 16곡도 같은 변환기에 각 곡 ID를 전달해 생성한다. Barber의 파생 MIDI를 다시 만들 때는 먼저 `python3 tools/restore_barber_articulation.py`를 실행한다. 이 출처 문서는 실제 오디오 청취·브라우저 프레임 성능·캐릭터 동작의 검증 결과를 대신하지 않는다. 해당 범위는 통합 검증 보고서를 따른다.
