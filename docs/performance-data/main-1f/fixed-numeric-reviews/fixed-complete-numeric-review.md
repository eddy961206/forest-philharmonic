# fixed28 전체 숫자 독립 검토

상태: **VERIFIED_RECORDED_NUMBERS_WITH_LIMITATIONS** · 기준 `1f8e5f16f1eee03140e13ba1ee66832841559604` · 후보 `dea7997c6278f10ff467815ab96b370362549b0c`.

**현재 숫자는 모든 장면·저사양 환경의 일관된 성능 개선을 입증하지 못해.** 최초 A 120행은 평균 완료시간 감소 56 / 증가 64, p95 감소 60 / 증가 60, ΔThreadTime 감소 42 / 증가 78이야. high desktop 역순 B 20행은 평균 감소 15 / 증가 5였어. 두 묶음을 합친 성공률이나 평균 개선율은 만들지 않았어.

Hall 근거리의 감소는 분명한 관찰이지만 wide·foyer의 증가, 모바일 high·medium의 다수 악화, Sphere high full 3D forest·peaks의 반복 증가를 함께 보고해야 해. 개별 수치는 아래 140행을 모두 남겼어.

## 대조 범위

- 원 집계기는 PASS, 28 jobs / 14 pairs / 140 rows, excluded 0, adaptive 0. 이 리뷰는 원 집계기를 재실행하지 않았어.
- 28개 닫힌 raw JSON과 140행의 숫자·조건을 대조했어. 원시 표본 2,240개, 각 제품·장면·실행당 n=8, 예열 4야.

- 요약의 입력 중 58개 JSON bytes/SHA를 확인했어. 28개 stdout은 이번에 다시 읽지 않았고 원 집계기와 log JSON의 SHA 기록을 대조했어. PNG는 파일 읽기부터 수행하지 않았어.
- 기록된 source before/after, revision, collector/fixture/helper hash, preset, actual quality, renderScale 1, viewport/DPR/pixelRatio, actualLite, fixture/씨드/장면 설정이 전후 맞아. baseline quality.js 404는 예상된 부재야.

## 미측정·해석 제한

- 140개 행은 동일한 앱·실행의 연속 표본/장면을 포함한 기술통계다. 독립 실험 140회 또는 개선 성공률로 사용하지 않는다. 최초 A 120행과 high desktop 역순 B 20행을 분리한다.
- 각 제품·장면·실행의 n=8, warmup=4이며 p95/p99는 nearest-rank 최대 표본이다. a/b를 합쳐 n=16 독립 표본으로 만들지 않고 CI나 유의성 검정을 만들지 않았다.
- 모든 실행은 Linux headless Chromium의 SwiftShader다. desktop viewport 및 mobile viewport/UA/touch 에뮬레이션이며 물리 GPU·실제 스마트폰·iOS/Android 성능과 같지 않다.
- completeMs는 실제 frame 호출과 동기 readPixels 대기를 포함한다. 역수를 FPS로 만들지 않는다. 이 묶음에는 FPS·1% Low·GPU query 시간·GPU/VRAM 바이트·로드 시간·발열·배터리 수치가 없다.
- 같은 preset, actual quality/scale, Lite 여부, 씨드, 장면/카메라 설정이 전후 같다는 것은 기록된 입력 동등성이다. 화면 픽셀 동일성이나 품질 합격은 이번 숫자 검토로 판정하지 않는다. PNG 파일을 읽지 않았다.
- low desktop와 모든 mobile은 기존 Lite 경로다. Sphere forest/peaks/ocean/clouds라는 이름이 같아도 해당 Lite 행을 full desktop cube 3D 세계 비용의 증거로 해석하지 않는다. high mobile의 렌더 픽셀비 1.5와 medium 1.0625, low 1.25는 서로 다른 품질이며 가로 비교 개선율을 만들지 않는다.
- 음표 스케줄러를 끄고 공연 시각을 합성한 fixture이므로 실제 오디오 경합·청감·glitch·실제 UI 동작/멀티플레이·장시간 안정성의 통과를 주장할 수 없다.
- ΔThreadTime은 계측을 포함한 페이지 renderer 메인 스레드 CPU 구간 시간이다. ΔTaskDuration/ScriptDuration 기본 timeTicks는 동기 대기·계측이 포함된 경과시간이고 CPU 사용률이 아니다. 다른 스레드·GPU 프로세스 전체 비용은 별도다. 중첩 phaseMeanMs를 합산하지 않는다.
- performance.memory 표본 heap과 CDP JSHeapUsedSize는 별도 JS 메모리 관측이다. 이 기록의 coarse heap이 여러 표본에서 같은 값인 점과 CDP/GC 변동을 보존한다. 두 값을 더하거나 VRAM/총 메모리 감소로 바꾸지 않는다. MiB=bytes/1048576이며 textures/geometries는 개수다.
- served source 전후는 각 실행에 기록된 12경로만 manifest와 직접 대조했다. baseline quality.js 404는 원래 파일 부재다. 나머지 manifest 파일·실제 HTTP 전체·주입 후 main/UUID와 원래 HTTP 응답은 구분해야 한다. 이 리뷰는 추가 Git/네트워크/브라우저 검증을 실행하지 않았다.
- 이번에는 58개 요약 입력 JSON의 bytes/SHA와 내용만 대조했으며 28개 stdout 로그는 읽지 않았다. 로그 SHA는 원 집계기가 검증해 저장한 값과 log JSON의 값이 일치함을 확인했다. 이전 개별 리뷰의 독립 stdout 검증과 이 범위를 혼동하지 않는다.
- Hall medium A에 앞선 2.294초 CPU 이미지 작업이 겹쳤을 가능성을 별도 주석으로 남긴다. 정확한 시각·프레임별 영향과 변동 원인은 미확정이며 값을 선택적으로 제거하지 않았다.
