# 레퍼토리 원본과 재현 방법

## 범위

- 신규 30곡을 홀과 스피어에 각각 15곡씩 추가했다. 기존 52곡 중 `elgar-pomp-and-circumstance`는 사용자 요청으로 전곡 편곡으로 교체했다. 최종 고유 곡 수는 82개다.
- 연주는 MIDI를 악기별 음표 데이터로 변환한 뒤 Web Audio 악기 샘플로 합성한다. YouTube 오디오·영상·녹음 파일은 연주 경로에 없다. 실황 참고 링크는 별도 창으로 열린다.
- 원곡의 관현악 총보, 밴드 판본, 피아노 축약보에서 만든 자체 편곡을 구분한다. 아래 판본 표와 앱의 프로그램·현재 연주 표시에 차이를 적었다.

## 원본 확인과 이용 조건

- Mutopia 7곡은 개별 원본 페이지의 Public Domain / CC BY / CC BY-SA 표시를 기록했다. 비발디 봄과 쇼팽 녹턴의 원본 및 파생 연주 데이터에는 CC BY-SA 3.0을, 파헬벨 캐논에는 CC BY 4.0을 유지한다. 출처, 기여자, 악기 배정·샘플 연주로 변환한 사실을 함께 표시한다.
- PDMX 원본은 [공식 데이터셋](https://zenodo.org/records/15571083)의 MIDI와 메타데이터다. 카탈로그에는 원본 페이지, 기여자, archive 경로, SHA-256을 남겼다. 개별 업로더의 CC0/PD 표시는 저작권 실사나 모든 국가에서의 원곡 권리 확인을 대체하지 않는다.
- PDMX 363281(푸른 도나우), 5871238(피아노 협주곡)은 dataset의 `license_conflict` 플래그가 있었다. 함께 제공된 MusicXML의 rights를 직접 확인했다. 웹 CC0와 내부 Public Domain 표시가 모두 재사용을 허용하는 선언임을 기록했다. 이 확인 범위를 넘어서 원곡·편집의 권리를 보증하지 않는다.
- **사브르의 춤:** [Classical MIDI](https://www.classicalmidi.co.uk/khachaturian.htm)의 `48.zip / 48.MID`를 사용했다. 시퀀서 이름은 unknown이며 사이트는 시퀀서의 허가를 요구한다. 현재 허가 증거는 확보하지 못했다. 따라서 `NOASSERTION`으로 기록하며 공개 라이선스나 자체 제작 원본이라고 주장하지 않는다. 배포 전에 이 데이터의 허가를 확보하거나 독립 제작한 연주 데이터로 교체해야 하는 미해결 항목이다. 곡 자체를 다른 작품으로 바꾸지는 않았다.
- 코드의 MIT 라이선스는 외부 악보·MIDI·샘플에 자동 적용되지 않는다. [CREDITS](../CREDITS.md)의 개별 조건이 적용된다.

## 변환과 편곡

1. MIDI type 0/1을 읽는다. 포트와 채널별 프로그램, 음량·표현, 서스테인 페달, 템포, 변박, 피치 벤드와 벤드 범위를 처리한다. MuseScore가 tick 0의 프로그램 변경 뒤에 쓰는 초기 포트 선언도 같은 포트로 처리한다.
2. 박자·템포를 초 단위로 적분한다. 음표의 순서·음높이·쉼·화음·반복·다이내믹을 원본에서 가져온다. velocity는 음표가 시작될 때 CC7/CC11을 반영한다. 지속 중 CC11의 연속 변화, MIDI 효과·모든 아티큘레이션은 현재 완전히 재현하지 않는다.
3. 원본의 공유 채널 때문에 플루트가 피치카토로 나오는 등 잘못된 음색은 파트 이름과 편성을 보고 카탈로그의 명시적 배정으로 수정했다. 문자열 아티큘레이션(피치카토/트레몰로)과 SATB 합창의 단원 배정은 유지한다.
4. 윌리엄 텔은 MIDI의 2/4 피날레 시작 417.310087초부터 연주한다. 차이콥스키 협주곡 파일에는 세 악장이 들어 있어 2악장 시작 1415.560549초 전에 잘랐다. 각각 마지막에 1.2초의 잔향 여유가 있다.
5. 발퀴레의 기행·꽃의 왈츠·투우사의 노래는 축약보의 음들을 음역·성부에 따라 현악·관악에 배정한 자체 편곡이다. 원관현악판을 그대로 전사한 것으로 표시하지 않는다. 같은 선율을 임의 반복해 길이를 늘리지 않았다.
6. 위풍당당은 기존 2분 6초 트리오에서 약 6분 44초의 전체 1번 행진곡으로 확장했다. CC0 피아노·합창 축약보의 전체 음표·반복·템포를 유지하고 최고음 선율, 내성, 최저음 베이스를 나누었다. 빠른 행진/첫 트리오/재현/마에스토소 합창/코다의 배합을 다르게 하고, 원본 박자와 저음에 맞는 작은북·큰북·팀파니·심벌즈 반주를 작성했다.
7. 합창은 모음 샘플이다. 가사를 발음하는 실황 합창은 아니다. 샘플 합성과 공간 음향의 구현이며 전문 악단의 실황 녹음과 동일한 음질을 보장하지 않는다.

## 재현

Node 18+와 Python 3, 음악 변환에는 mido 1.3.3이 필요하다. 샘플을 다시 만들 때만 ffmpeg와 네트워크가 필요하다. 실행 앱은 이미 저장된 JSON/MP3를 사용한다.

```sh
python3 -m venv tools/.cache/repertoire-venv
tools/.cache/repertoire-venv/bin/pip install -r tools/requirements-music.txt
tools/.cache/repertoire-venv/bin/python tools/build_repertoire.py
tools/.cache/repertoire-venv/bin/python tools/build_repertoire.py --check
tools/.cache/repertoire-venv/bin/python -m unittest discover -s tests -p test_midi_score.py -v
npm test
npm start
```

`tools/repertoire.json`은 31개 레코드다. 그중 `replacesExisting: true`인 엘가 1개를 제외한 30개가 신규 곡이다. `tools/scores/`의 MIDI와 카탈로그 체크섬이 다르면 빌드가 실패한다. 생성된 데이터에는 출처와 판본이 포함된다. 기존 `build_music.py`도 마지막에 이 빌더를 호출하여 신규 곡과 업그레이드한 엘가가 목록에서 빠지지 않게 했다.

샘플 재생성: `npm run build:samples`. FluidR3 타악기 6종은 SoundFont의 PCM 스트라이크를 직접 추출하고 원본 SHA-256을 확인한다. 샘플별 시작 지연·RMS 보정·잔향 길이를 `analyze_samples.py`로 측정한다.
