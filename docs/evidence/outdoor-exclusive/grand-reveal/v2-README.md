## 제외한 시도

- 기존 v1 영상은 공간 단독 끝 구도 때문에 사용자 전경 요구를 충족하지 못했다. 실패 자료로 그대로 보존한다.
- hall-v2.webm은 근접 후면이 막히면 중앙 경로 검사도 건너뛰는 분기로 하강 장면이 없었다. 시간/활성 검사는 통과했지만 하강 전경 검증은 표본 0개로 실패했다.
- 이 분기를 수정한 hall-v2-final / sphere-v2-final만 최종 v2 근거다.

실제 iPhone/Safari와 전곡 모든 순간은 검증하지 않았다. 완료 후 9224 앱 탭 0개를 확인했다. 커밋·푸시·영상 인코딩은 담당하지 않았다.
