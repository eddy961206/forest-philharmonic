# 연속 영상 검토 기록

실제 WebGL + Web Audio 녹화에서 시간순 프레임을 추출하고, 매 렌더 프레임의 관절 궤적과 함께 검토했어. 아래 관찰은 녹화한 대표 구간에 대한 결과야. 전체 82곡을 전곡 영상으로 확인했다는 의미는 아니야.

녹화 원본의 곡, 시간, 카메라, 활성 연주 프레임, 소스 해시는 `recording-summary.json`에 있어. 자세한 프레임 자료는 `frame-telemetry.json.gz`에 있어. 이름을 누르면 구간을 바꿀 수 있는 `review.html`과 정상 속도 MP4를 함께 저장했어.

## 데스크톱

| 사례 | 관찰 |
| --- | --- |
| violin | 활의 왕복과 왼손 넥 이동을 확인했어. 팔이 길어지거나 팔꿈치가 반대로 튀는 모습은 표본에서 보이지 않았어. |
| raccoon | 비올라를 켜는 동안 두 눈 무늬가 분리되어 유지돼. 머리 회전 중 무늬가 머리 안으로 잘리거나 긴 검은 띠로 이어지는 모습은 보이지 않았어. |
| cello | 엔드핀이 바닥에 남고, 오른손은 활의 손잡이 쪽을 따라가. 쉼표 전환 때 악기를 놓치는 모습은 보이지 않았어. |
| bass | 빠른 악절에서 활 방향이 바뀌어도 뼈 길이가 유지돼. 확대 카메라로 오른손과 활의 접점을 확인했어. |
| flute | 실제 연주 구간을 재녹화했어. 악기가 입 옆에서 가로 방향을 유지하고 양손이 몸통 앞에서 잡아. |
| oboe | 긴 악절의 연주와 짧은 쉼에서 악기·양손이 함께 움직여. 갑작스러운 손 위치 변화는 보이지 않았어. |
| clarinet | 입과 악기의 연결, 앞쪽 두 손의 높이 순서를 확인했어. |
| bassoon | 상체 흔들림과 악기 기울기가 함께 이어지고 손이 악기를 따라가. |
| horn | 양팔이 몸 앞에서 서로 뒤집히지 않고 밸브와 벨 쪽을 나눠 잡아. |
| trumpet | 입의 위치를 따라 악기가 움직이고 손이 밸브 부근을 유지해. |
| brass | 트롬본의 슬라이드와 오른손이 함께 움직여. 너구리 눈 무늬도 가까이 확인했어. |
| tuba | 큰 악기를 받치는 자세가 유지되고 손이 반대편으로 교차하지 않아. |
| sax | 손이 두 그립을 유지하고 악기 하단은 아래로 향해. |
| piccolo | 축과 크기 수정 후 입 옆에서 가로로 연주해. 쉼표 동안 악기가 순간적으로 다른 방향으로 바뀌지 않아. |
| englishHorn | 기울어진 리드 악기를 위아래 두 손으로 잡고 입 연결을 유지해. |
| harp | 양손이 현 근처를 이동하고 어깨에서 멀리 늘어나지 않아. 실제 현과 손의 위치를 옆에서 확인했어. |
| piano | 덮개가 가리지 않는 뒤쪽 카메라로 양손을 확인했어. 두 손이 건반 위에서 서로 순서를 뒤집지 않고 음역에 맞춰 이동해. |
| celesta | 양손이 실제 건반 높이에서 따로 이동하고 내려간 건반과 위치가 맞아. |
| choir | 악보 폴더를 잡은 양손과 입 모양 변화가 이어져. 팔꿈치가 뒤집히는 모습은 보이지 않았어. |
| timpani | 북 사이 이동과 양손 교대, 낮은 타점에서의 반동을 확인했어. |
| snare | 짧은 채가 손에 붙은 상태로 북 표면을 향해 왕복해. |
| tom | 북 타점에서 채가 내려갔다가 올라와. 주변 트라이앵글 단원도 함께 확인했어. |
| bassDrum | 채가 큰 북의 표면으로 내려가고 손에서 분리되지 않아. |
| cymbals | 거치된 심벌즈 표면을 향해 채가 움직이고 상체를 뚫는 큰 회전은 보이지 않았어. |
| triangle | 왼손은 고리를 지지하고 오른손의 금속 채 하나로 아래쪽 변을 쳐. |
| tambourine | 테두리를 지지하는 손과 북면을 두드리는 손이 분리돼. 두 개의 팀파니 채는 없어. |
| mallet | 좌우 음역에 따라 두 채가 건반 위를 이동하고 음표 때 내려가는 모습을 확인했어. |
| bells | 채가 관 위로 내려찍는 대신 관을 향해 움직여. 실제 타점이 있는 옆면을 확인했어. |
| pizzicato | 짧은 쉼표 사이에도 활이 사라지지 않아. 손에 든 활은 아래로 향하고 손의 작은 뜯기 동작이 이어져. |
| conductor | 박자에 맞춘 지휘봉과 왼손의 곡선 이동을 확인했어. 팔꿈치가 급히 반대편으로 바뀌지 않아. |
| bow | 일어나기, 허리 숙이기, 복귀, 착석을 녹화했어. 고정 악기로 뒤로 팔을 뻗지 않고 인사 자세로 이어져. |
| exit | 단원 51명이 모두 퇴장한 마지막 상태까지 녹화했어. 큰 악기는 무대에 남고 연주자는 이동 자세로 걸어가. |
| entry | 무대가 빈 상태부터 마지막 단원의 착석까지 녹화했어. 최종 상태는 착석 39명·서 있는 합창 12명·이동 중 0명이야. 고정 악기를 들고 걸어가거나 뒤로 팔을 뻗는 모습은 보이지 않았어. |
| organ | 파이프에 가려진 앞쪽 시점을 제외하고 뒤쪽에서 재녹화했어. 양손이 건반에 닿은 채 움직이고 손과 건반이 떨어지는 모습은 보이지 않았어. |

## 모바일 에뮬레이션

390×844, DPR 2, Lite 설정의 Chrome에서 `raccoon`, `piano`, `triangle`, `bells`, `organ`을 각각 8초 녹화했어. 단순화된 팔과 얼굴에서도 손·악기 연결과 너구리 무늬가 유지되는 걸 확인했어. 실제 iPhone Safari에서 녹화한 결과는 아니야.

## 비교 영상

이전 Git 커밋 `79b5c025e469c0654fde8c7ccdbc49aed2cea6a1`의 모든 `public/js` 파일을 불러와 같은 곡·시간·캐릭터 기준 카메라로 8개 사례를 다시 녹화했어. `brass`, `triangle`, `tambourine`, `mallet`, `bells`, `piccolo`, `pizzicato`, `piano`가 대상이야. 큰 악기 배치를 옮긴 사례는 배경도 달라져. 왼쪽이 이전 커밋, 오른쪽이 수정본이며 수정본의 실제 소리를 사용해. 별도의 속도 변경이나 프레임 보간은 없어.

## 검토 한계

- 샘플 사이의 갑작스러운 손 이동은 프레임별 궤적으로 보완했어. 모든 피부·악기 표면의 충돌을 계산한 검사는 아니야.
- 관악기 손가락과 현악기 운지는 캐릭터의 작은 손 형태로 단순화돼 있어.
- 화면 전체가 나오는 입퇴장 영상에서는 모든 단원의 세부 관절을 같은 해상도로 판독할 수 없어. 이를 전체 단원에 대한 수치 검사와 악기별 근접 영상으로 보완했어.


## 마지막 얼굴 충돌 재검사

벨 채의 주둥이 관통을 비교 영상에서 발견한 뒤 타점을 낮추고 반동·손잡이 방향을 고쳤어. 고정 타악기 7개와 모바일 벨을 다시 녹화했고 0/2/4/6초 연속 장면과 프레임 궤적을 확인했어. 얼굴 관통은 자동 타원체 검사로 회귀 방지해. 수정 후 얼굴 여유는 전체 악보 표본에서 1.13247 이상이야. 앞선 531/1200 관통은 수정 중간 버전의 실제 10초 벨 측정이며 최초 Git 기준 버전과 혼동하면 안 돼.
